StarThink CRM

A full-stack CRM built for creative agencies — managing clients, projects, workflows, and team collaboration. Deployed entirely on Cloudflare's edge infrastructure.

React 18 Vite 6 Tailwind CSS v4 Cloudflare Workers Cloudflare D1 TanStack Query

Overview

StarThink CRM is a full-stack customer relationship management platform purpose-built for creative agencies. It brings client management, project tracking, creative and content production workflows, advertising campaigns, and team collaboration into a single system. The entire stack runs on Cloudflare's edge network — a React frontend served from Cloudflare Pages and a Hono-based API running on Cloudflare Workers backed by a D1 (SQLite) database — giving the platform global low-latency access with no traditional server infrastructure to manage.

Project Goals

  • 🗂️ Client Lifecycle Management — Create, edit, deactivate, and delete client records
  • 📁 Project Tracking — Members, milestones, and status tracking per project
  • 🎬 Creative & Content Workflows — Production shoots, edit tasks, and a full content pipeline from idea to published
  • 🧑‍💻 Task Boards — Dedicated web development and graphic design task boards per project
  • 📢 Advertising Tracking — Ad account and campaign tracking
  • 📅 Unified Calendar — Cross-module event calendar
  • 🔐 Role-Based Access — Eleven distinct roles, from admin down to client portal users
  • 🧾 Audit Trail — Full activity audit logging across the system
  • 🔔 Real-Time Notifications — In-app notifications for team members

Technical Stack

Frontend

  • React 18 - Component-based UI
  • Vite 6 - Build tool and dev server
  • Tailwind CSS v4 - Utility-first styling, configured via @import "tailwindcss" with no tailwind.config.ts needed
  • React Router v6 - Client-side routing
  • TanStack Query v5 - Server state and data fetching
  • Recharts - Dashboard charts
  • Lucide React - Icon set

API & Backend

  • Cloudflare Workers - Serverless edge compute for the API
  • Hono v4 - Lightweight web framework for the Worker API
  • JWT (HS256) - Authentication with refresh tokens

Database & Hosting

  • Cloudflare D1 - SQLite-based distributed database
  • Cloudflare Pages - Frontend hosting
  • Cloudflare Workers - API hosting

Getting Started

Prerequisites

  • Node.js 18+
  • Wrangler CLI (npm i -g wrangler)
  • A Cloudflare account

1. Install Dependencies

npm install

2. Provision the D1 Database

wrangler d1 create starthink-crm

Copy the database_id from the output and paste it into apps/worker/wrangler.toml.

3. Run Database Migrations

Apply the schema and all migrations in order:

wrangler d1 execute starthink-crm --local --file=apps/worker/src/db/schema.sql
wrangler d1 execute starthink-crm --local --file=apps/worker/src/db/projects.sql
wrangler d1 execute starthink-crm --local --file=apps/worker/src/db/creative.sql
wrangler d1 execute starthink-crm --local --file=apps/worker/src/db/content.sql
wrangler d1 execute starthink-crm --local --file=apps/worker/src/db/clients.sql
wrangler d1 execute starthink-crm --local --file=apps/worker/src/db/ads.sql
wrangler d1 execute starthink-crm --local --file=apps/worker/src/db/audit.sql
wrangler d1 execute starthink-crm --local --file=apps/worker/src/db/milestones.sql
wrangler d1 execute starthink-crm --local --file=apps/worker/src/db/dev_tasks.sql
wrangler d1 execute starthink-crm --local --file=apps/worker/src/db/design_tasks.sql
wrangler d1 execute starthink-crm --local --file=apps/worker/src/db/client_requests.sql
wrangler d1 execute starthink-crm --local --file=apps/worker/src/db/client_portal.sql
wrangler d1 execute starthink-crm --local --file=apps/worker/src/db/add_assignee_ids.sql

4. Start Local Development

Run the API and frontend in separate terminals:

# API — http://localhost:8787
npm run dev:worker

# Frontend — http://localhost:3000
npm run dev:web

The frontend proxies /api/* to http://localhost:8787 via Vite's proxy config.

Dev Commands

npm run dev:web        # Start frontend dev server
npm run dev:worker     # Start worker dev server
npm run build:web      # Build frontend for production
npm run lint           # ESLint
npm run format         # Prettier
npm run type-check     # TypeScript type check (all packages)

Deployment

Deploy API (Cloudflare Workers)

npm run deploy:worker
# or
npx wrangler deploy --config apps/worker/wrangler.toml

Deploy Frontend (Cloudflare Pages)

npm run deploy:web
# or
npm run build:web && npx wrangler pages deploy apps/web/dist --project-name starthink-crm

Live URLs

  • Frontend - starthink-crm.pages.dev
  • API - starthink-crm-api.starthinkmy.workers.dev

Key Conventions

  • All shared TypeScript types live in packages/shared/src/types/
  • Worker routes follow /api/<resource> (e.g. /api/clients, /api/projects)
  • Auth middleware: apps/worker/src/middleware/auth.ts
  • API fetch wrapper: apps/web/src/lib/api.ts — use api.get<T>(), api.post<T>(), etc.
  • TanStack Query client: apps/web/src/lib/queryClient.ts
  • Tailwind is configured via @import "tailwindcss" in apps/web/src/index.css — no tailwind.config.ts needed
  • Dark mode via ThemeContext + @custom-variant dark in CSS

Environment Variables

Set in apps/worker/wrangler.toml under [vars]:

  • ENVIRONMENT - development or production
  • ALLOWED_ORIGINS - Comma-separated list of allowed CORS origins
  • JWT_SECRET - Secret key for signing JWT tokens (set as a Wrangler secret)

To set secrets:

wrangler secret put JWT_SECRET --config apps/worker/wrangler.toml
